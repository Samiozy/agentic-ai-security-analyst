# Instructor starter references

These teaching examples show simulated service reconnaissance and cached/real web
responses, including Chain → Retrieval → Agent progression. Keep them as cited
references; grading evidence must come from our separately implemented live lab
and real model calls, not the supplied stand-ins.

Security maintenance: the web server and web notebook reject HTTP redirects
so responses cannot send reconnaissance outside the authorized host list.
The original versions remain available in Git history.
