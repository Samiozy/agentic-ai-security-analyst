# Knowledge bases

The provided CVE and web guidance Markdown files are preserved and extended with
`scanner_guidance.md` for the new probes. `loader.py` converts Markdown headings
to sections for local retrieval. Partner A maintains CVE material; Partner B
maintains web guidance. Update `SOURCES.md` for every advisory. Confirm a CVE
against an authoritative source before claiming that it applies to the lab;
matching a product version alone is insufficient. Coverage is reviewer-verified.
